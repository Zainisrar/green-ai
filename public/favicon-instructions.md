# Favicon Setup Instructions

To complete the favicon setup, you need to generate the following files from your GREEN Limited logo:

## Required Files:
1. `favicon.ico` (16x16, 32x32, 48x48 sizes in one file)
2. `favicon-16x16.png`
3. `favicon-32x32.png`
4. `apple-touch-icon.png` (180x180)
5. `safari-pinned-tab.svg` (monochrome SVG)

## How to Generate:
1. Use your GREEN Limited logo from `/images/heroSection/logo.png`
2. Use online tools like:
   - https://realfavicongenerator.net/
   - https://favicon.io/
   - https://www.favicon-generator.org/

## Steps:
1. Upload your logo
2. Configure settings (background color: #ffffff, theme color: #4CAF50)
3. Download the generated files
4. Replace this file and place all generated files in the `/public` directory
